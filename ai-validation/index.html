04 / Independent work

Different systems, related mechanisms

Independent researchers have studied several observable failure classes relevant to RCA. Each correspondence is linked to its own publication and classified by what it actually shows; none is silently promoted into validation of the full WCT/RCA framework.

Propagation · PD-01

Small errors become collective failure

From Spark to Fire models directed message dependencies and identifies cascade amplification, topology sensitivity and false-consensus persistence across six multi-agent frameworks.

Original paper ↗ · Strong external mechanism comparison; RCA metric not independently tested.

Conformity Generates Collective Misalignment studies how social interaction can cause groups of agents to enter misaligned collective states.

Original paper ↗ · Structural convergence; different model assumptions.

Memory · ledger 197

Risk accumulates over long horizons

Remembering More, Risking More compares memory-equipped agents against a NullMemory counterfactual and observes risks that rise with accumulated memory exposure.

External correction · PD-03

Separate safety memory

MAGE introduces shadow memory to detect long-horizon threats before important agent actions, supplying an implementation analogue for external monitoring.

Original paper ↗ · Functional correspondence; not WCT substrate validation.

Detect cross-agent pathways

CASPIAN studies detection and attribution of multi-agent cascade attacks through cross-channel causal monitoring.

Original paper ↗ · A methodological comparator for topology-sensitive RCA models.

Reward Hacking Challenges Oversight studies 17 language models and 38 tasks, including spontaneous reward hacking and agents adapting to evaluator feedback.

05 / Mathematical bridge

One model must earn its explanatory reach

A simple RCA model has propagation rate ν, correction rate μ and net growth λ = ν − μ. Writing R = μ/ν gives λ = ν(1 − R). This algebra makes a testable boundary explicit, but it is also familiar stability mathematics; it is not, by itself, proof that WCT generated AI behavior.

Single aggregate system

λ = ν − μ

Hypothesis: estimated propagation and correction rates should forecast whether deviations amplify within a specified setting.

Network-aware extension · proposed

dx/dt = (B − D)x

Transfer matrix B and correction matrix D account for network structure, agent roles and heterogeneous interventions. Test against conventional network-dynamics baselines.

The explicit WCT-to-RCA derivation and universal interpretation remain open. Record shared mathematical form, operational mapping, and new predictive contribution as distinct claims.

06 / Next-stage validation

Three tests that could change the evidence level

Cascade forecasting

Estimate rates on a training set. Freeze an RCA prediction for unseen agents and interaction structures. Compare with graph-degree and standard cascade baselines.

Possible benchmark: ACIArena.

Anchor survival

Define a fixed constraint-retention score before experimentation. Predict failure risk from memory exposure and correction frequency; compare with NullMemory and simple duration baselines.

Independent source: Longitudinal Memory Risk.

Intervention effectiveness

Compare no protection, existing monitoring, and RCA-inspired external correction on held-out attacks. Report time-to-detection, false positives, task utility and recovery.

Comparators: From Spark to Fire and MAGE.

Promotion rule: New empirical validation requires an operational metric and frozen success rule, an independent dataset or investigator, uncertainty estimates, relevant negative controls and comparison against established baseline models. Similar wording in a later paper is insufficient.

08 / The actual research target

Can a frozen RCA metric predict failure before it occurs?

The next substantial result is not another set of overlapping papers. It is an independently reproducible demonstration that a prespecified RCA model anticipates cascading failure, memory degradation or correction breakdown in previously unseen systems—and adds value beyond simpler alternatives.
