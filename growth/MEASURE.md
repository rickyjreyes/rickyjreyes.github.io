# Distribution metrics template
Manual collection; no performance or view numbers are assumed.

Each platform post gets an ID, source, destination and hypotheses before publication.

| Date | Post ID | Platform | Creative version | Hook | URL | Impressions | 3s views | Completed views | Shares | Site clicks | Substack subscribers | Notes |
|---|---|---|---|---|---|---:|---:|---:|---:|---:|---:|---|
| YYYY-MM-DD | A-v1 | Shorts | ring_question | Can a wave organize itself? | /discover/?utm_source=youtube&utm_medium=short&utm_campaign=wct_visual_launch | | | | | | | |

Primary comparison metrics:
- Hook retention = 3-second views / impressions (only where platform definitions make this comparison meaningful)
- Completion rate = completed views / video starts, platform-specific
- Share rate = shares / impressions
- Click-through rate = site clicks / impressions (subject to platform reporting)
- Subscriber conversion = new subscriptions attributable to a campaign / tracked landing visits

Use UTMs by channel, e.g. utm_source=threads|x|bluesky|youtube|substack, utm_medium=social|short|note, utm_campaign=wct_visual_launch. Do not interpret a single winning hook as statistically established; compare like-for-like post times and traffic sources. Report absolute sample sizes.
