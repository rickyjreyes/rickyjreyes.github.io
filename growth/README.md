# WCT visual-first growth assets

These files support a public discovery path without replacing the full technical research archive.

- Home page (`/index.html`): direct question, original video embed, visible follow/verify routes
- `/discover/index.html`: visual landing page with original numerical videos, real experiment, related math, newsletter links
- `/growth.css`: scoped styling for homepage video and discovery page
- `30-DAY-LAUNCH.md`: four-week editorial and production plan
- `SOCIAL-POSTS.md`: 20 sourced post drafts
- `CLIP-STORYBOARDS.md`: six production-ready edit scripts using existing assets
- `MEASURE.md`: performance-tracking template

**No posts have been scheduled or published. No new MP4 edits were rendered.** Existing video files are embedded by reference. The user can approve the homepage update by merging the PR.

## Smoke checks before merge
1. Open PR preview or local `/discover/` and `/`; test at 375px and 1200px widths.
2. Confirm both local MP4 files and poster image load; video controls work and motion is paused under reduced-motion preference.
3. Open every research/Zenodo/GWTC/Substack destination.
4. Check homepage source contains Open Graph image and `summary_large_image`.
5. Check focus/keyboard navigation and images' accessible alternative text.
6. Confirm existing bibliography, priority, patents, equations, Lean, and research routes remain intact.
7. Review labels distinguishing computation, experiment, Lean proof, and empirical inference.
