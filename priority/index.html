03 · conditional signal

CMS is positive—but the background model matters.

The fixed-waveform G2 test returned A=0.9708618 and Δχ²=126.2832 under the declared background. Alternative smooth backgrounds weaken the apparent significance, so the result stays conditional rather than being promoted to a collider discovery.

04 · failed route preserved

ATLAS closes before the frozen target is tested.

The V6.1 background route failed its own adequacy gates with no qualifying nuisance dimension. The target frequency was never evaluated and the final holdout remained untouched. The failed route stays visible instead of being tuned away.

05 · separate public dataset

NIST adds a different evidence layer.

Fe II selected the same k=31.3265306122449 at 120, 160, and 200 bins, with 0/5000 null exceedances at each setting. That is public-data numerical support, but it is still an author-run analysis rather than independent replication.

06 · unresolved

The next decisive step is independence.

The current record contains positive, conditional, and failed analysis paths. What would materially change the scientific status now is independent replication, stronger null/model robustness, and a physical explanation that survives across datasets.
